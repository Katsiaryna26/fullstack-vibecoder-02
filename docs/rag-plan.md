# План RAG-системы для Telegram-бота

Цель: подключить базу знаний к Supabase Edge Function, которая принимает сообщения Telegram и отвечает с учётом найденного контекста.

1. Подготовить базу знаний: определить источники, очистить документы и разделить их на осмысленные фрагменты.
2. Создать embeddings для фрагментов и сохранить их в Supabase Postgres с расширением `pgvector`.
3. Добавить метаданные: источник, заголовок, права доступа и дату обновления.
4. Реализовать поиск контекста: embedding вопроса → vector search → подбор релевантных фрагментов.
5. Подключить поиск к Telegram Edge Function и передавать найденный контекст вместе с вопросом в LLM.
6. Добавить безопасность: проверку доступа, ограничения размера и частоты запросов, защиту секретов и обработку ошибок.
7. Настроить обновление и удаление документов, логирование и тестовые вопросы для оценки качества ответов.
